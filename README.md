# WearShifter

用可穿戴设备控制 Mac 光标的原型合集。各子目录是独立的 Swift 工程，分别构建和测试。

| 目录 | 说明 |
| --- | --- |
| [airpods-mouse](airpods-mouse/README.md) | 用 AirPods（戴在头上、握在手里或放在开盖的充电仓里）控制光标的 macOS 菜单栏应用 |
| [watch-mouse](watch-mouse/README.md) | 用 Apple Watch 手腕转动控制光标，手表经蓝牙发给 Mac 菜单栏应用；含手势采集和分析工具 |

两个原型原先分别在 `MoYiC6/airpods-mouse` 和 `MoYiC6/watch-mouse`，提交历史已一并导入。
